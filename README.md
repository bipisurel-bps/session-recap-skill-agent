# Session Recap Skill

OpenClaw skill untuk bikin ringkasan singkat dari session yang lagi jalan.

## Trigger
- "tldr", "recap", "summarize", "where are we", "udah ngapain aja", `/tldr`

## Format
```
## Done
- <action> <object>. <result>.

## Current task
- Task: <nama>
- Status: <complete | in progress | blocked>
- Last step: <terakhir ngapain>
- Next step: <selanjutnya ngapain>
```

## Install
Copy folder `tldr/` ke `~/.openclaw/workspace/skills/` atau `~/.agents/skills/`.
